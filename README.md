## 🎯 Mục đích của Repository
Repository này được tạo ra để:
- Lưu trữ các bài tập thực hành, source code trong quá trình tự học Java.
- Theo dõi sự tiến bộ của bản thân qua từng ngày.
- Làm tài liệu tra cứu nhanh các cú pháp, thuật toán và kiến thức OOP (Lập trình hướng đối tượng) bằng Java.

---

## 📂 Cấu trúc thư mục (Dự kiến)
Dưới đây là cách sắp xếp các bài học trong repo này (bạn có thể thay đổi tùy ý):

- **`🌱 01_Basics/`**: Cú pháp cơ bản, kiểu dữ liệu, vòng lặp, câu lệnh rẽ nhánh.
- **`📦 02_OOP/`**: Lập trình hướng đối tượng (Class, Object, Inheritance, Polymorphism,...).
- **`🗂️ 03_DataStructures/`**: Cấu trúc dữ liệu và giải thuật trong Java (Array, List, Map,...).
- **`🚀 04_Projects/`**: Các bài tập lớn hoặc dự án mini thực hành tổng hợp.

---

## 🛠️ Công cụ sử dụng
- **Ngôn ngữ:** Java (JDK 17+)
- **IDE/Editor:** Visual Studio Code (hoặc Eclipse/IntelliJ)
- **Quản lý phiên bản:** Git & GitHub

## 🚀 Cách chạy code trong repo
Nếu bạn clone repo này về máy, bạn có thể chạy các file Java thông qua Terminal bằng lệnh:

```bash
# 1. Biên dịch file Java thành file .class
javac TenFile.java

# 2. Chạy file vừa biên dịch
java TenFile
